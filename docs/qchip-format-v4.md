# `.qchip` 文件格式 v4：芯片设计图

v4 延续单文件 SQLite 存储及 [v3 的全部表](qchip-format-v3.md)，`PRAGMA user_version=4`，`meta.format=qchip`。软件版本号保持 0.3.1。

## 新增表

| 表 | 内容 |
| --- | --- |
| `chip_design` | 单张设计图，`id=1`；原始文件名、图片字节 BLOB、顺时针旋转角度（0–360°）。 |
| `design_markers` | `device_id` 主键及器件外键、`design_id=1` 设计图外键、原图归一化坐标 `x`、`y`（0–1）。 |

设计图不依赖外部路径。坐标以未旋转的原图左上角为原点，右下角为 `(1,1)`，不影响逻辑构型中的器件坐标。旋转只修改显示角度，保留图片原始内容及标注坐标。查看界面让标注随图旋转，同时保持文字正向和固定显示大小。

标注以器件 UUID 关联，显示名称查询 `devices.label`，器件改名后同步更新。每个器件最多一个标注；重复放置更新原标注位置。删除器件级联删除其标注；替换或移除设计图级联删除全部标注，替换时旋转角度归零。比特与耦合器均可标注。

## 接口

- `chip_design()` 返回设计图字节及元数据，无图时返回 `None`。
- `set_chip_design(file_name, data)` 原子替换设计图，调用界面先检查图片可解码。
- `remove_chip_design()` 移除图片及所有标注，保留器件和逻辑构型。
- `set_design_rotation(angle)` 保存旋转角度，按 360° 归一化。
- `design_markers()` 返回标注位置及关联器件名称、类型。
- `set_design_marker(device_id, x, y)` 新增或更新原图归一化坐标。
- `remove_design_marker(device_id)` 删除对应标注。

设计图、标注和旋转操作立即写入数据库；数据库备份包含全部内容。XLSX/CSV、逻辑构型 PNG/SVG 导出沿用原有内容。

GUI 支持撤回和恢复全部项目编辑。历史仅保留在当前会话内，通过 SQLite 临时触发器记录发生变化的行，撤回/恢复以事务写回主数据库；不新增持久表、不改变 v4 格式。备份及重新打开项目包含操作后的当前数据，不携带编辑历史。

## 升级与兼容

打开旧文件时，沿用现有迁移机制：先生成同目录 `文件.pre-vN.qchip`（N 为原版本）备份，再逐级升级至 v4。已有同名备份时停止升级。v3→v4 只新增两张表，不改写器件、参数、接线或附件。

原有 Windows 0.3.1 发布版使用 v3，不能打开 v4。升级后的项目需使用当前源码；原有发布版可继续打开迁移前的 v3 备份。本次未重新编译发布包。
