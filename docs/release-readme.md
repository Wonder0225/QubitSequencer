# Qubit Sequencer 0.3.3 · Windows 桌面版

完整解压后双击 `QubitSequencer.exe`。请保持 EXE、`_internal` 及其他文件的相对位置。打开 `examples/surface_d3_complete.qchip` 可查看完整 d=3 旋转表面码项目；其中的参数、工作点和接线均为模拟数据。

顶部项目栏负责新建、打开、备份、全局工作点、导出和主题切换，左侧导航切换芯片构型、参数数据表、制冷机接线和参数历史。构型详情可调整宽度或收起，数据表支持横向/纵向、筛选和完整内容提示。

详情与器件弹窗共享同一份草稿。“保存更改”写入当前对象，“取消更改”恢复其已保存值，关闭弹窗保留草稿。打开其他文件、新建或退出时，会提示保存全部、放弃或取消。参数登记与接线操作确认后立即写入，不受器件草稿取消影响。Delete 仅在画布具有焦点时删除对象。

顶部工作点同时影响参数详情、数据表和导出。主题按钮或“视图 > 深色模式”切换配色；导出 PNG/SVG 使用当前主题。线路相关操作先选择表格行，“解除关联”还要求当前行关联器件。

最新完整说明见 `user-guide.md`。上一版 `user-guide.pdf` 可在程序“帮助 > 使用说明 PDF”打开。实际项目请保存在发布目录以外的可写位置，并定期使用“备份”。本地编译包文件格式为 SQLite v7，旧 v1–v6 项目打开时会自动备份和迁移。迁移后的文件需用本地新编译包打开，切回 GitHub 的旧发布包需使用迁移前备份。

“文件 > 打开最近的文件”提供最近项目，Ctrl+R 打开可搜索列表。频率采用 f_{10} 显示，各参数名称支持简单 TeX；图层中比特参数优先、耦合器参数置后。新记录使用北京时间 +08:00，旧 UTC 历史按同一时刻换算显示和导出。

登记参数时可添加多个文件、拖入文件或粘贴图像；附件随历史记录内嵌保存。历史页支持图片预览、文本/代码编辑、附件替换及版本恢复，移除的附件也可恢复。附件区采用紧凑按钮；参数表、历史表的数字和文本统一左对齐、垂直居中。

芯片构型页提供“查看设计图”按钮，支持文件／剪贴板图片导入、旋转、人工标注比特、耦合器、读取线及 filter 名称，点击查看参数。读取线依次点击起点和终点，自动吸附格点／半格，支持斜向直线；虚线预览，Esc 取消。图片和标注内嵌保存至项目。设计图测试示例位于 `examples/chip_design_release_demo.qchip`，标注位置留空，可自行对应。

读取线可连接多个比特，filter 可放置在线上；显示读取线时淡化耦合器及其连接，可用“显示读取线和 filter”隐藏读取结构。参数表默认纵向，“显示参数”菜单控制字段可见性。制冷机接线支持盘位、温级元件、放大器及检线登记，见 `cryostat-wiring.md`。

Ctrl+Z 撤回项目编辑，Ctrl+Y 或 Ctrl+Shift+Z 恢复，也可使用“编辑”菜单。当前会话保留最近 100 步；关闭或切换项目后清空。涉及已保存数据的撤回与恢复立即写回当前文件。

设计图中的“半透明标注”按钮以 50% 不透明度显示名称、引线及位置标记，再次点击恢复正常显示；点击查看参数与拖动编辑均可继续使用。“帮助 > 版本信息”显示软件版本、当前文件格式及支持的 `.qchip` 版本。

“查看设计图”右侧的“查看能级图”在构型页内用水平线段展示标定 f10，可调节比特间距、显示由非谐计算的 f21 虚线，并切换分列／横向布局。图例包含全部比特及标定状态，支持 PNG/SVG 导出。

通过“添加元件”菜单放置元件，默认名称按放置顺序编号，右键点击元件可删除。比特详情和参数数据表默认显示实验常用标定参数，次要字段可按需显示。
