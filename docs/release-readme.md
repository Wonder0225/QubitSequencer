# Qubit Sequencer 0.2.1 · Windows 桌面版

双击 `QubitSequencer.exe` 启动。选择“文件 > 打开 .qchip”，打开 `examples/surface_d3_complete.qchip`，即可查看完整 d=3 旋转表面码演示项目。

演示项目中的参数、工作点和制冷机接线都是**模拟数据**，仅用于查看软件效果，不能作为实验结果使用。

通过“视图 > 深色模式”切换界面；设置会保留到下次启动。导出 PNG/SVG 时使用当前的明暗配色。参数数据表可切换横向和纵向显示。

完整说明见同目录 `user-guide.pdf`，也可在软件中选择“帮助 > 使用说明 PDF”。`.qchip` 文件保存所有实际编辑；请将自己的芯片文件放在有写入权限的位置，并定期使用“文件 > 另存备份”。

本压缩包为 Windows x64 文件夹版本。解压后请保持 `QubitSequencer.exe`、`_internal` 文件夹及其他文件的相对位置。
