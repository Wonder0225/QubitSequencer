# Qubit Sequencer 0.4.3

- 新增样品盒构型，内置 56 芯和 100 芯模板。模板目录支持 JSON，更新后重启即可加载。芯片元件可经样品盒接口关联制冷机端口或开关分支，支持在图面查看并导出接线对应关系。
- 支持自定义芯片元件，可在样品盒和制冷机接线中选用。构型图按类型配色，底部图例按类型列出元件名称。
- 在「制冷机布线」点击「检查接线类型」，可核对当前项目的普通端口和开关分支。XY/Z 端口兼容 XY/Z 线和 Z 线，其余端口要求类型一致。
- 「视图」提供多栏模式，可组合排列各工作页，软件重启后恢复工作区。

当前文件格式为 `.qchip` v10 和 `.qfridge` v3。打开旧项目时会自动备份后迁移。

下载并完整解压 Windows x64 压缩包后，运行 `QubitSequencer.exe`。最新使用说明见包内 `user-guide.md`。随附 PDF 为较早版本。
