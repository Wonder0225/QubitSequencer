# Qubit Sequencer 0.2.2

## 修复和调整

- 修复点击比特/耦合器后下方注释消失的问题。
- “适配芯片”按实际元件范围重新定位图例，减少空底板造成的多余留白。
- 窗口尺寸变化时，已适配的芯片与注释会一起重新适配；手动缩放或拖动后保留自由视图。
- 自定义比特身份按设置的名称显示在图例中，多个身份自动换行并使用稳定配色。
- 身份参数图能够显示自定义身份文本；PNG/SVG 导出使用相同的注释布局。

## 使用

下载 `QubitSequencer-0.2.2-win64.zip` 并完整解压，双击 `QubitSequencer.exe`。保持 `_internal` 与 EXE 的相对位置。使用说明见 `user-guide.pdf`。

实际 `.qchip` 项目请保存到发布目录之外。随包的 d=3 芯片项目为模拟数据。

SHA256 校验值见 `SHA256SUMS.txt`。
