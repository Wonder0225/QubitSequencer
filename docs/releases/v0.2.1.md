# Qubit Sequencer 0.2.1

用于超导量子芯片构型、器件参数、耦合关系和制冷机接线登记的 Python/PySide6 桌面软件。

## 下载和启动

1. 下载 `QubitSequencer-0.2.1-win64.zip`，完整解压到有写入权限的位置。
2. 双击 `QubitSequencer.exe`，无需另行安装 Python。
3. 打开 `examples/surface_d3_complete.qchip` 查看完整 d=3 旋转表面码模拟项目。
4. 使用说明见发布包中的 `user-guide.pdf`。

请保持 EXE、`_internal` 和其他随包文件的相对位置。实际芯片项目建议保存到发布目录之外。

## 功能

- 可扩展正方格子、旋转表面码模板和自定义构型。
- Transmon、固定/可调耦合器、直接耦合和独立的比特—耦合器连接。
- 参数、单位、自定义字段、工作点、历史记录和制冷机接线登记。
- 点击元件弹出编辑窗口，支持简单 TeX 标签和横向/纵向数据表。
- XLSX/CSV 数据导出、PNG/SVG 构型与参数图导出。
- 深色模式、应用图标、字体清晰度调整。

## 文件和范围

芯片项目使用 `.qchip` SQLite v2 格式；旧 v1 文件会备份后迁移。所有演示数据均为模拟值。

当前支持单人编辑。标定实验与附件已有底层存储接口，完整管理界面仍待后续开发。

下载包的 SHA256 校验值见 `SHA256SUMS.txt`。
