# Qubit Sequencer 0.4.5

- 低温线路元件支持电线编号。同一线路段、同一温级的元件可拖动换序。微波开关可登记 C 公共端及编号控制端的电线，并可单独登记 Reset 复位电线。
- 线路图支持级联开关、合路开关和多端口对照。Bias Tee 可关联 RF 控制线与 DC 偏置端口，样品接线以 RF 端口编号显示。
- 制冷机布线支持快捷接线选择开关末端和公共输出、批量调整接线分配，以及端口状态备注和附件。
- 样品盒可单独或批量导出带样品名和末页接线图的横向 PDF。接线大礼包另含两张样品盒接线图与 Excel 接线表。

芯片格式为 `.qchip` v10，制冷机格式为 `.qfridge` v7。旧项目打开时会先备份再迁移。完整解压 Windows x64 ZIP 后运行 `QubitSequencer.exe`。
