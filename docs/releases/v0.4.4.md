# Qubit Sequencer 0.4.4

- 新增多栏快捷接线：在芯片构型和制冷机单盘中依次选择元件与端口，按选择顺序预览配对并批量接线。读取线的读入、读出接口分别匹配；支持批量撤回和恢复。
- 芯片构型图新增样品盒接口与信号图层，制冷机接线图层显示当前项目分配和旧记录。样品盒智能接线视图展示盘号、端口和开关分支，支持 PNG、SVG、PDF 导出。
- 改进芯片与制冷机图面选择交互，支持框选、Ctrl 多选和右键平移；制冷机盘面可批量设置端口状态或解除分配。
- 微波开关端口显示分支占用比例，并支持逐分支手动占用和登记图纸编号。

芯片格式为 `.qchip` v10，制冷机格式为 `.qfridge` v3。打开旧项目时先自动备份后迁移。

下载并完整解压 Windows x64 压缩包后运行 `QubitSequencer.exe`。最新使用说明见包内 `user-guide.md`；随附 PDF 为较早版本。
