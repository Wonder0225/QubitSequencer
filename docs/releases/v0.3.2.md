# Qubit Sequencer 0.3.2

- 芯片构型页增加“查看设计图”按钮，可随时切换设计图与逻辑构型。新建或后续导入图片，支持任意角度旋转、缩放和平移。
- 设计图支持人工标注比特和耦合器名称、拖动调整位置及点击查看参数。图片、旋转角度和标注内嵌到项目；器件改名后标注同步更新。
- 项目编辑支持 Ctrl+Z 撤回、Ctrl+Y 或 Ctrl+Shift+Z 恢复，以及“编辑”菜单。器件、连接、参数、附件、接线、设计图与共享草稿均纳入历史；对话框输入也支持撤回和恢复。
- 当前会话保留最近 100 步历史，关闭或切换项目后清空。撤回已保存的编辑会立即写回当前文件。
- 增加设计图测试示例 `examples/chip_design_release_demo.qchip`，包含模拟参数和 12 个演示比特，图中标注位置留空，供使用者自行对应。

文件格式升级至 SQLite v4。旧 v1/v2/v3 项目打开时先自动备份再迁移，保留原参数、附件和接线。升级后的项目须使用 0.3.2 或相应源码打开；回到旧版时使用迁移前 `.pre-vN.qchip` 备份。

Windows x64 发布包附带最新 Markdown 使用说明、配图、设计图示例及许可证。PDF 保留此前版本，设计图与撤回／恢复操作以 `user-guide.md` 为准。
