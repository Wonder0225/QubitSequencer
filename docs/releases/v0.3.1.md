# Qubit Sequencer 0.3.1

- “文件 > 打开最近的文件”显示最近访问的芯片；Ctrl+R 打开文件名和路径分层的搜索列表。记录最多 20 项，跨启动保留；清除记录不会删除项目文件。
- 比特与耦合器频率统一显示为 `f_{10}`，寿命和设计参数采用上下标。预置及自定义参数名称在图层、详情、登记标题、历史、表头和图片中使用简单 TeX 排版。
- 新记录采用北京时间 UTC+08:00。旧 UTC 历史保留原始值，显示和导出时换算为同一时刻的北京时间；不同偏移的记录按实际时间排序。
- 图层参数按比特、两比特耦合、物理连接、耦合器顺序展示。

## 参数标定附件更新（2026-10-05）

- 参数登记支持多文件附件、拖入文件及 Ctrl+V 粘贴图像，内容内嵌到芯片文件。
- 历史记录支持图片缩放、代码/文本编辑、改名、说明、替换及可恢复移除。
- 附件保存完整版本历史，恢复旧版本时追加新版本；参数和附件使用同一事务，失败整体回滚。
- 附件工具栏采用紧凑按钮；参数表和历史表的数字、文本及表头统一左对齐、垂直居中。

文件格式升级至 SQLite v3，参数键及关联保持兼容；旧 v1/v2 文件打开前自动备份，再迁移至 v3。迁移后的文件需使用当前版本打开。默认参数旧名称通过读取接口兼容映射，自定义名称保留原值。

Windows 发布包包含最新 Markdown 使用说明及配图，PDF 保留此前版本，新增附件操作以 Markdown 为准。

最近文件列表参考 [VS Code 官方 Quick Pick / Open Recent 说明](https://code.visualstudio.com/docs/editing/getting-started/tips-and-tricks#_open-a-recent-folder-or-workspace)，采用文件名与路径两行布局、即时搜索和键盘打开。
