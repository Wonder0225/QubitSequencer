# Qubit Sequencer 0.2.3

## 参数图排版调整

- 根据文字的实际尺寸自动选择字号，短数值优先居中显示。
- 比特的多组端口名称分行显示；耦合器端口紧凑分行，过长文本在器件旁完整展示。
- 连接和两比特耦合数据自动避开器件与其他文字，细引线指明所属连接，参数文字可点击。
- 补全经耦合器的两比特有效耦合参数展示。
- PNG/SVG 导出采用与界面一致的布局，包含更新后的 d=3 模拟示例图片与中文使用说明。

## 使用

完整解压 `QubitSequencer-0.2.3-win64.zip`，双击 `QubitSequencer.exe`。保留 `_internal` 与 EXE 的相对位置。

实际 `.qchip` 项目请保存到发布目录之外；随包的 d=3 示例是模拟数据。
