# Qubit Sequencer 0.3.0

0.3.0 将桌面界面整理为紧凑科研工作台，并补齐器件草稿与文件离开流程。

## 界面

- 顶部项目栏统一新建、打开、备份、全局工作点、导出及明暗切换。
- 左侧导航提供芯片构型、参数数据表、制冷机接线与参数历史。
- 构型工具条可适应窗口宽度；详情可调宽、收起，窗口布局与主题可保留。
- 两种主题使用统一 14px 正文、16px 标题、32px 操作按钮和矢量图标；焦点、选中、禁用与危险操作有明确状态。
- 数据表保留完整表头/单元格提示、原值、单位和筛选计数；接线按钮按明确行选择启用。

## 编辑与保存

- 详情与器件弹窗共用编辑器和每对象草稿。
- 保存当前对象写入文件；取消恢复其已保存值；关闭弹窗、切页或切主题保留草稿。
- 新建、打开或关闭主窗口前可保存全部、放弃或取消离开；保存失败时保留文件和输入。
- 参数与接线确认后立即写入，草稿取消不会撤销已登记记录。
- Delete 快捷键限定画布焦点，文本输入保留正常删除行为。

## 文档与兼容

中文图文说明、PDF、明暗四页截图及器件弹窗演示同步更新。原有构型图的物理角色、热图与分类配色保持；`.qchip` 格式仍为 v2，v1 迁移和备份流程延续。
