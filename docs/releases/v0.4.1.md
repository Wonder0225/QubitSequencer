# Qubit Sequencer 0.4.1

- 新增独立制冷机布线工作区。通过冷盘总览查看端口，进入单盘登记样品、图纸编号和低温线路，可应用线路预设、管理微波开关分支，并导出布线表或包含关联样品的项目压缩包。
- 芯片构型支持读取线、可调 filter 和“读取腔耦合”。同一条读取线可连接多个比特。设计图支持剪贴板导入、旋转和半透明标注。
- 构型页内嵌能级图，默认显示已标定的 f₁₀，可选显示由非谐计算的 f₂₁、调节比特间距及导出图片。
- 参数数据表默认纵向，可逐项显示字段及拖动表头调整列宽。π 脉冲面积自动计算，Ramsey T₂* 和 Spin Echo T₂ 分开登记，旧的通用 T₂ 记录归入 Ramsey。

当前文件格式为 `.qchip` v8 和 `.qfridge` v2。打开旧版文件时会先生成迁移备份。“帮助 > 版本信息”可查看所支持的格式。

下载 Windows x64 ZIP 并完整解压后运行 `QubitSequencer.exe`。压缩包包含制冷机布线和芯片模拟示例。最新操作说明见包内的 `user-guide.md`，随附 PDF 为较早版本。
