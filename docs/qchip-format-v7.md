# `.qchip` 文件格式 v7：读取线端点

v7 保留 [v6](qchip-format-v6.md) 的器件、参数及共享读取关联，扩展读取线几何：

- `devices.readout_direction` 支持 `horizontal`、`vertical`、`angled`。
- `devices.readout_angle` 为可空角度（度）。非空时按中心坐标、线长及角度确定起点和终点，显示路径严格经过两端。屏幕坐标中 X 向右、Y 向下。
- 新建读取线两端分别吸附到整数或半整数坐标，中心可以是四分之一格；正反选择顺序均保存。
- 空角度表示旧读取线，沿用横／纵方向及原有平行避让。升级不会改变旧读取线或 filter 坐标。
- filter 的相对位置仍为 0–1，支持斜向读取线；比特连接线使用线段上的最近点。
- XLSX/CSV 的读取线表增加起点 X/Y、终点 X/Y。

v6→v7 在事务中重建器件表，保留所有原列与子表关联，角度默认为空；提交前检查外键。打开旧项目前生成 `.pre-vN.qchip` 备份。完成一条读取线作为一次撤回／恢复操作，未完成的端点选择不写入文件。

软件版本号仍为 0.3.2；最新本地编译包使用 v7，GitHub 原有 0.3.2 包仍为 v4。切回旧包需使用迁移前备份。
