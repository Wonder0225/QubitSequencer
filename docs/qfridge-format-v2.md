# `.qfridge` 格式 v2：物理线路与开关分支

`.qfridge` 是独立 SQLite 文件，`meta.format=qfridge`，`PRAGMA user_version=2`。打开 v1 项目前，软件在同目录创建 `.pre-v1.qfridge` 备份并升级；已有端口、分配及历史文字不变，不自动应用预设。原 v1 结构及文件路径、迁移和打包约定见 [v1 格式说明](qfridge-format-v1.md)。

| 数据 | 内容 |
| --- | --- |
| `port_circuits` | 每个物理端口的 JSON 线路；`components` 是有显示顺序的温级记录，`switch` 是可选分支编号列表。`legacy_details` 可保存用户选择导入的旧线路完整资料。 |
| `assignments` | 无开关端口的样品分配；原有历史图纸文字和迁移记录保留。 |
| `branch_assignments` | 开关端口各分支的样品分配，同一分支至多一个样品，可关联多个器件。 |
| `meta` | 另可保存 `board_template:盘号`，使新盘后续可应用其模板对应的线路预设。 |

每条温级记录包含温级、类别、数值、单位、原始标记、端点和备注。数值为 `0` 表示明确登记的零，`null` 表示未登记；`500M` 等原图标记原文保存。记录顺序用于显示，不表示未经确认的信号方向。线路归物理端口所有，不随分配的样品改变。已有分配转换成开关分支时需明确选择归属；有分配的分支不能直接移除。

`.qchip` v8 在器件上增加固定文本字段 `drawing_number`，量子比特默认空白。制冷机引用样品及器件 ID，查看或导出时读取当前值；不可用或删除时保留原有引用。旧接线的图纸文字仍存于其分配记录，不与比特图纸编号混用。

预设按提供的盘面线路表登记已展示数据；B21–B26、B45–B46、未展示的直流线路保持未知，图中样品和图纸编号不导入。新项目、新盘和现有项目均需用户主动选择应用；现有线路默认不覆盖。预设提供的 F/O4 六路开关不记录开关的当前位置。

导入旧接线时保留迁移原始记录。用户可选择将其中温级元件和完整详细资料复制到物理端口；放大器与检线原资料可只读查看，不推断接线方向，也不计算放大或衰减。
