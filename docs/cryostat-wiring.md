# 制冷机接线登记

字段类别参考 `GATE20251216.pptx` 的第 11–19 页端口接线表、第 21–23 页放大器表，以及第 2–8 页检线记录。文稿仅用于确定登记类别，软件不导入其中的实际端口、器件、衰减或放大器数据。

| 类别 | 登记项 | 文稿中的依据 |
| --- | --- | --- |
| 线路定位与用途 | 制冷机、盘号、端口、仪器及通道、线缆编号／颜色、XY、Z、XY/Z、读取输入／输出、滤波器控制、泵浦等 | A–F 盘、端口号、控制与读取线路分类 |
| 样品映射 | 样品引脚、图纸编号／信号名称、关联比特或耦合器 | Sample、图纸编号、Q/C/F、读取输入／输出和 TWPA 端口 |
| 温级元件 | 温级／位置、元件类型、名称／编号、数值、单位、端子／通道、备注 | 3 K、STILL、50 mK、MC 下的衰减器、IR 滤波器、低通、隔离器及微波开关 |
| 放大链 | 低温／室温放大器位置、型号、编号、频段、电源引脚及接线 | 放大器按盘位对应，频段及 GND／Vd／Vg 接线 |
| 放大器工作参数 | 放大器编号、温度 K、Vd V、Id mA、Vg V、备注 | 同一放大器不同温度下的工作值 |
| 检线记录 | 时间、装样状态、测试功率 dBm、频段 GHz、实测传输 dB、结论、测试条件／备注 | 装样前／带样品、测试功率、传输结果及异常处理 |

进入“制冷机接线”，点击“新增线路”或双击已有线路。在“盘位与样品、温级元件、放大链、检线记录”四个页签中填写，最后点击“保存线路”统一写入。保存失败会保留窗口内的输入。

温级元件按实际信号顺序排列，“上移／下移”调整顺序。同一温级可以填写多行，例如衰减器、另一只衰减器和红外滤波器。温级、元件类型、用途可自定义；红外滤波器等编号填入名称／编号，数值栏仅填写数值，单位另选或输入。微波开关、隔离器、合路器的端子填入“端子／通道”。

放大器表中记录编号，下方工作参数表可选择编号并分别登记各温度的 Vd、Id、Vg。频段栏可填写 `3–9` 这样的范围，单位见表头。原始接线表中未明确的信息保持为空，不根据端口或文字自动推断。

配置中的衰减值和检线的实测传输值分开保存，不互相覆盖或自动换算。未登记的数值留空；填写 `0` 表示已登记零值。检线可新增多条，分别记录装样前后或改变测试条件后的结果。

主页面按盘号、用途及关键词筛选。关键词包括样品引脚、图纸编号、元件编号和关联器件。选中线路后，下方详情显示温级配置、放大链和全部检线记录。“关联器件”允许一条线路关联多个比特、耦合器、读取线或 filter；图纸编号和信号名称是独立文字，不自动匹配器件。

XLSX／CSV 的“接线”表保留原有七列，新增盘位、样品、完整温级元件、放大链、不同温度工作参数及检线记录，各数值单位随内容保存。一次线路保存作为一步撤回／恢复；删除线路时新增登记及器件关联一起删除，撤回时一起恢复。窗口内单元格编辑、增删行和调整元件顺序也支持 Ctrl+Z、Ctrl+Y／Ctrl+Shift+Z。

接线登记在 v5 中新增 `wiring_details` 表；当前源码及 2026-10-08 的本地编译版使用 v7，另支持读取线与 filter 元件，均可关联制冷机线路。打开 v1–v6 项目先自动生成迁移前备份，旧项目未登记的新类别保持为空。此前上传 GitHub 的 0.3.2 包使用 v4，切回旧包时使用迁移前备份；支持格式可在“帮助 > 版本信息”查看。
