# 制冷机接线登记

## 多样品制冷机项目

左侧选择“制冷机布线”，首先显示只读的冷盘总览。尚未打开项目时展示默认盘位；使用页面上的“新建 .qfridge”或“打开 .qfridge”管理实际项目，也可通过“文件”菜单打开。总览支持右键拖动平移、滚轮缩放及“适配视图”。框选或 Ctrl 多选不同盘上的端口后，点击工具栏的“查看线路图”可按温级对照。

从盘号下拉框选择单盘，或在总览中双击端口进入对应盘。A、B、C、D、E、F 分别显示为独立盘面，总览根据窗口宽度自动排列；必要时右键拖动画布查看其余盘面。单盘视图可双击端口分配样品及器件，右侧提供端口编辑和删除；“返回总览”切回只读图。端口的亮环表示已配置。可切换到布线表，按盘号、样品、线路用途或占用状态筛选。

亮环颜色对应已关联的样品，页面图例列出颜色和样品名称；端口内部颜色仍表示线路类型。一个开关端口连接多个样品时，亮环分段显示各样品颜色；没有关联样品的手动占用分支以灰色段表示。鼠标悬停可查看各分支的样品名称。筛选、重新打开项目或切换主题时，样品颜色对应关系保持一致。

单盘选择端口后，可在详情中选择“未分配”“已占用”或“已损坏”。关联样品后自动显示为已占用；也可手动标记占用，保留已经接好但未在项目中分配的线路。手动占用或损坏的端口会从新分配、旧线路迁移和线路预设中排除；取消手动标记后可继续操作，已有分配不会被清除。若端口仍有关联样品，取消手动标记后状态仍为已占用，需解除样品分配才能变为未分配。

在单盘视图按住 Ctrl 依次点击端口，或拖动空白处框选多个端口，再从右侧状态下拉框选择状态，即可一次设置全部所选端口；可一次撤回或恢复。批量选择“未分配”只取消手动标记，不会解除已有的样品连接；仍有关联样品的端口继续显示为已占用。

多选后也可点击“解除分配”，预览并确认需要解除的样品连接；开关端口会列出其已分配分支。手动占用或损坏的端口及手动占用的分支会跳过，物理线路和手动标记保留。迁移原记录如包含在解除范围内会一并移除，界面会提示；整个批量操作可一次撤回或恢复。

已占用端口可选填接线目标图纸编号；有开关时可为整个端口或各分支分别登记。该编号独立于关联样品中的比特图纸编号，显示在布线表和导出中。手动状态及编号随 `.qfridge` 保存，支持撤回／恢复。

微波开关端口在盘面中显示占用分支数，例如 `2/6`；详情逐项列出各分支的分配及占用情况。选择具体分支后，可勾选“当前分支手动占用”并填写该分支图纸编号；手动占用的分支不能新增或修改分配，其他空闲分支不受影响。整端口标记为占用或损坏时，所有分支均受限制，原分配和分支标记保留。取消分支标记不会解除已有样品分配。

默认盘位按实验室提供的 A、B、C 和 D–F 读出盘图建立。A、B、C 分别为 54、54、61 个端口，D、E、F 各为 4 个端口。端口颜色沿用芯片构型图配色：蓝色表示 XY/Z 线，灰色表示直流，金色表示读入，青绿色表示读出；配置后增加亮环。可新增、删除、移动端口并编辑编号和类型。端口类型与分配后的实际线路用途分别保存；一个端口一次分配给一个样品，但可关联该样品多个器件。

点击「检查接线类型」可手动核对当前制冷机项目中所有已分配的线路，包括开关分支。XY/Z 端口兼容 XY/Z 线和 Z 线，其余端口要求与线路用途一致。结果按盘号、端口和分支列出不匹配项。检查为只读操作。

“新建盘”可选择内置 A–F 模板，或创建空白正方／三角格子盘；模板复制端口的布局、编号和类型，不复制样品分配。进入单盘后可切换格子类型，点击“新增端口”再点击格点放置，也可直接拖动现有端口；新建和移动时自动吸附，并阻止放在已有端口附近。按 Esc 可取消放置。打开旧项目或切换格子时，所有端口自动吸附到最近可用格点，避免重叠；样品和线路分配保持不变。旧项目首次需要调整时会先创建备份；切换格子不作为撤回步骤，并会清空本项目此前的撤回记录。

新建制冷机或使用盘位模板时可选择实验室线路预设；已有项目可点击“应用线路预设”预览并选择端口。已有物理线路默认不勾选，勾选后才覆盖；没有图纸资料的端口保持未登记。预设不填写样品、引脚或图纸编号。线路归属于物理端口，移除样品不会移除物理线路。

单盘选择端口后点击“查看线路图”。单选时可点击或双击图中元件查看和编辑，使用“新增元件”“删除”“前移”“后移”修改线路。框选或 Ctrl 多选时，各路按温级对齐，只读查看。开关分支可展开，右键拖动平移，滚轮缩放。0 dB 是已登记值，IR、IR1、IR2 归为滤波器并保留标记，500M 和 I1 等仍按原文显示。支持自定义温级和同一温级的多项记录。

“元件库”可登记常用元件及型号、频段、增益或衰减等默认参数。选用时会复制到当前线路，之后可独立编辑。“配置微波开关”可登记端口的开关和分支。F 盘 O4 预设包含 1–6 号分支。在段落下拉框切换“共用段”与各分支，可分别添加线路元件。新加开关时已有连接需选择归属分支。调整后点击“保存线路”，可一次撤回或恢复。布线表和导出分别标记共用段与分支专属元件。

放大器等元件可填写电线编号。微波开关按 C 公共端及多路侧 1、2、3……登记控制电线，表格标明对应的射频分支。可选的 Reset 行只登记复位控制电线。控制接法按具体型号的说明登记。在线路图中左键拖到同一段、同温级的另一个元件上即可互换次序。 [Radiall SPnT 电气原理图](https://www.radiall.com/media/files/Switches_Catalog_Web_LR_1_.pdf) · [Keysight 多端口开关手册](https://www.keysight.com/us/en/assets/9018-01797/service-manuals/9018-01797.pdf)

内置 **Bias Tee（偏置器）** 用于在 RF 线路上叠加直流偏置，具有 RF、DC、RF+DC 三个端子。RF 路径通过隔直电容接到公共端，DC 路径通过射频扼流电感接到公共端。在线路图中可按温级登记型号、频段和 RF 插入损耗，并在备注填写直流额定电流、电压、端口隔离及测试温度。低温性能取决于具体型号和测试条件。 [Mini-Circuits 原理说明](https://blog.minicircuits.com/rf-microwave-bias-tee-basics/) · [Marki Microwave 低温实测](https://markimicrowave.com/technical-resources/application-notes/cryogenic_performance_of_marki_microwave_products/)

编辑线路中的 Bias Tee 时，选择“信号输入端口（RF）”和“直流输入端口（DC）”。线路图会在 RF 路径和 DC 支路上分别标出端口编号。给样品接线时选择 RF 控制线端口，样品盒接线继续显示该编号。接线保存后，RF 和 DC 端口的详情与线路图会显示自动关联的直流接线及样品。解除 RF 接线会同时解除这项关联。

在“配置微波开关”的“接线方向”选择“一路到多路”或“多路到一路”。前者表示公共端可接到所选分支，后者表示各分支可分别接入公共端。开关画在其登记的温级列，分支从所属开关右侧引出。箭头随所选方向变化。已有线路未登记方向时显示为未标注。

在段落下拉框中选择已有分支，点击“配置微波开关”可在该段末端添加下一级开关。下级路径以 `1/2` 这类编号表示，可继续添加更多级。只有末端支路可分配样品。若原分支已接线或手动占用，保存时需选择承接原分配、占用标记和目标图纸编号的末端支路。

“配置合路开关”可勾选同一物理端口内的两条或更多末端支路，并登记公共输出的编号、开关温级和型号。每条输入保留自己的元件，选中公共输出可继续添加元件。双击图中的合路开关可重新选择输入，或修改公共输出编号和参数。保存改名时，公共输出上的元件、样品分配、占用标记和目标图纸编号会转到新编号。若多个输入各有样品分配或目标图纸编号冲突，须先处理冲突。

为带合路开关的端口点击“分配／编辑”时，在线路图上点选可接线的末端分支或公共输出，再点“确定”。接入合路开关的上游支路仍显示在图中，可查看其元件。

手动占用的开关端口仍可编辑线路元件、开关参数和合路开关。新增分路开关、修改分路编号或移除分路开关前，须先取消整端口的手动占用标记。

在芯片构型的比特详情中填写固定的“图纸编号”。制冷机端口关联比特后按器件 ID 从样品读取最新编号，线路用途单独显示；样品暂不可用或器件删除时保留关联并提示。布线表和 CSV/XLSX 导出包含物理线路、分支、样品和图纸编号。

“迁移旧接线”预览旧线路及器件，勾选需要迁移的行并确认目标端口和分支。未勾选的线路留在原样品中；迁移先备份 `.qchip`，成功后从原样品移除所选线路。请先关闭其他窗口中打开的该样品。迁移不支持撤回，可使用备份恢复；原温级元件、放大链及检线信息保留，可在端口的“查看迁移原记录”中只读查看。用户可选择在低温线路窗口导入旧温级元件，原始详细资料也会保存在端口线路中并可只读查看。

“样品管理”可关联、重新定位或移除样品。“导出 > 打包导出 ZIP”包含项目和所有关联样品的独立副本，解压后打开 `project.qfridge`。普通 `.qfridge` 只引用样品文件，移动样品后可使用“重新定位样品”。“导出 > 导出布线表”输出 XLSX 或 CSV。样品盒接口及版本说明见 [样品盒与接线文件格式](sample-box-formats.md)。

多栏模式下同时显示芯片构型和制冷机布线，先将当前芯片关联到制冷机项目并为元件登记样品盒接口。在构型图多选元件、制冷机单盘多选目标端口后点击“快捷接线”。普通端口按规则自动匹配。选择带微波开关的端口后，在预览的“目标端口”下拉框中手动选择末端分支或公共输出，同一物理端口的不同末端可分别分配。读取线的读入与读出按端口类型匹配，普通接口采用目标端口类型。写入前会重新检查，失败整批回滚，成功后可在制冷机页面一次撤回或恢复。

要调整已有分配，在单盘的盘位图中开启“快速调整”。框选或 Ctrl 多选来源端口，点击“记录来源”，再选择同样数量的目标端口并点击“预览调整”。可以换盘选目标，列表按两侧的选择顺序配对。开关端口有多个候选时，在线路图上选择具体的末端分支或公共输出。通常将分配迁移到空闲目标。两组各自已有分配时，可勾选“交换两组分配”，让目标分配移回对应的来源端。已手动占用、损坏或类型不兼容的接线端会阻止提交。一次撤回可恢复整批操作，低温线路和端口状态按原位置保留。

默认配对按两侧逐个点击的先后顺序寻找类型兼容的可用端口；按住 Ctrl 可依次选择，取消后重新选择的对象排到末尾。框选一次选中多个对象时按画面从上到下、从左到右确定其组内顺序。读取线的已登记接口按读入、读出顺序展开；已连接的接口不会占用候选端口，类型不匹配的端口留给后续兼容接口，可在预览中调整。

芯片构型的参数下拉框包含样品盒接口和信号图层。制冷机接线图层显示当前制冷机项目和样品中未迁移的旧接线，并标明来源；未打开项目或未关联当前样品时给出提示。构型图导出使用相同数据。

## 原有单样品接线记录

原 `.qchip` 内的旧接线数据保留；原单样品接线编辑页已由 `.qfridge` 工作区替代。关联样品后可用“迁移旧接线”转移选中的记录，未选择的记录留在原文件中。

旧接线字段类别参考 `GATE20251216.pptx`；新线路预设仅使用本次提供的 A–F 盘截图中明确给出的记录，不导入其中的样品分配和图纸编号。

| 类别 | 登记项 | 文稿中的依据 |
| --- | --- | --- |
| 线路定位与用途 | 制冷机、盘号、端口、仪器及通道、线缆编号／颜色、XY、Z、XY/Z、读入／读出、滤波器控制、泵浦等 | A–F 盘、端口号、控制与读取线路分类 |
| 样品映射 | 样品引脚、图纸编号／信号名称、关联比特或耦合器 | Sample、图纸编号、Q/C/F、读入／读出和 TWPA 端口 |
| 温级元件 | 温级／位置、元件类型、名称／编号、数值、单位、端子／通道、备注 | 3 K、STILL、50 mK、MC 下的衰减器、IR 滤波器、低通、隔离器及微波开关 |
| 放大链 | 低温／室温放大器位置、型号、编号、频段、电源引脚及接线 | 放大器按盘位对应，频段及 GND／Vd／Vg 接线 |
| 放大器工作参数 | 放大器编号、温度 K、Vd V、Id mA、Vg V、备注 | 同一放大器不同温度下的工作值 |
| 检线记录 | 时间、装样状态、测试功率 dBm、频段 GHz、实测传输 dB、结论、测试条件／备注 | 装样前／带样品、测试功率、传输结果及异常处理 |

迁移后的旧记录可在对应端口的“查看迁移原记录”中只读查看。原始温级、放大器、检线及备注均保留。旧 `.qchip` 的 XLSX／CSV 导出仍包含尚未迁移的接线记录。

旧接线登记在 `.qchip` v5 中新增 `wiring_details` 表。旧项目打开时先备份再升级，未登记的新类别保持为空。支持格式可在“帮助 > 版本信息”查看。
