# 制冷机接线登记

## 多样品制冷机项目

左侧选择“制冷机布线”，首先显示只读的冷盘总览。尚未打开项目时展示默认盘位；使用页面上的“新建 .qfridge”或“打开 .qfridge”管理实际项目，也可通过“文件”菜单打开。总览支持拖动空白平移、滚轮缩放，以及“适配视图”，但不能编辑端口。

从盘号下拉框选择单盘，或在总览中双击端口进入对应盘。A、B、C、D、E、F 分别显示为独立盘面，总览根据窗口宽度自动排列；必要时拖动画布查看其余盘面。单盘视图可双击端口分配样品及器件，右侧提供端口编辑和删除；“返回总览”切回只读图。端口的亮环表示已配置。可切换到布线表，按盘号、样品、线路用途或占用状态筛选。

默认盘位按实验室提供的 A、B、C 和 D–F 读出盘图建立。A、B、C 分别为 54、54、61 个端口，D、E、F 各为 4 个端口。端口颜色沿用芯片构型图配色：蓝色表示 XY/Z 线，灰色表示直流，金色表示读入，青绿色表示读出；配置后增加亮环。可新增、删除、移动端口并编辑编号和类型。端口类型与分配后的实际线路用途分别保存；一个端口一次分配给一个样品，但可关联该样品多个器件。

“新建盘”可选择内置 A–F 模板，或创建空白正方／三角格子盘；模板复制端口的布局、编号和类型，不复制样品分配。进入单盘后可切换格子类型，点击“新增端口”再点击格点放置，也可直接拖动现有端口；新建和移动时自动吸附，并阻止放在已有端口附近。按 Esc 可取消放置。打开旧项目或切换格子时，所有端口自动吸附到最近可用格点，避免重叠；样品和线路分配保持不变。旧项目首次需要调整时会先创建备份；切换格子不作为撤回步骤，并会清空本项目此前的撤回记录。

新建制冷机或使用盘位模板时可选择实验室线路预设；已有项目可点击“应用线路预设”预览并选择端口。已有物理线路默认不勾选，勾选后才覆盖；没有图纸资料的端口保持未登记。预设不填写样品、引脚或图纸编号。线路归属于物理端口，移除样品不会移除物理线路。

单盘选择端口后点击“查看 / 编辑低温线路”，按 3 K、STILL、50 mK、MC 查看示意并编辑表格。0 dB 是已登记值，500M、IR、IR1、IR2 和 I1 等保留原图文字，不推断含义或信号方向。支持任意温级和同一温级的多条记录。F 盘 O4 预设包含微波开关和 1–6 号分支；也可在其他端口启用开关。每个分支可分别分配一个样品及多个器件；转换已有分配时必须选择归属分支。亮环表示端口或其分支已有分配。

在芯片构型的比特详情中填写固定的“图纸编号”。制冷机端口关联比特后按器件 ID 从样品读取最新编号，线路用途单独显示；样品暂不可用或器件删除时保留关联并提示。布线表和 CSV/XLSX 导出包含物理线路、分支、样品和图纸编号。

“迁移旧接线”预览旧线路及器件，勾选需要迁移的行并确认目标端口和分支。未勾选的线路留在原样品中；迁移先备份 `.qchip`，成功后从原样品移除所选线路。请先关闭其他窗口中打开的该样品。迁移不支持撤回，可使用备份恢复；原温级元件、放大链及检线信息保留，可在端口的“查看迁移原记录”中只读查看。用户可选择在低温线路窗口导入旧温级元件，原始详细资料也会保存在端口线路中并可只读查看。

“样品管理”可关联、重新定位或移除样品。“导出 > 打包导出 ZIP”包含项目和所有关联样品的独立副本，解压后打开 `project.qfridge`。普通 `.qfridge` 只引用样品文件；移动样品后可使用“重新定位样品”。“导出 > 导出布线表”输出 XLSX 或 CSV。格式说明见 [`.qfridge` 格式 v2](qfridge-format-v2.md)。

## 原有单样品接线记录

原 `.qchip` 内的旧接线数据保留；原单样品接线编辑页已由 `.qfridge` 工作区替代。关联样品后可用“迁移旧接线”转移选中的记录，未选择的记录留在原文件中。

旧接线字段类别参考 `GATE20251216.pptx`；新线路预设仅使用本次提供的 A–F 盘截图中明确给出的记录，不导入其中的样品分配和图纸编号。

| 类别 | 登记项 | 文稿中的依据 |
| --- | --- | --- |
| 线路定位与用途 | 制冷机、盘号、端口、仪器及通道、线缆编号／颜色、XY、Z、XY/Z、读入／读出、滤波器控制、泵浦等 | A–F 盘、端口号、控制与读取线路分类 |
| 样品映射 | 样品引脚、图纸编号／信号名称、关联比特或耦合器 | Sample、图纸编号、Q/C/F、读入／读出和 TWPA 端口 |
| 温级元件 | 温级／位置、元件类型、名称／编号、数值、单位、端子／通道、备注 | 3 K、STILL、50 mK、MC 下的衰减器、IR 滤波器、低通、隔离器及微波开关 |
| 放大链 | 低温／室温放大器位置、型号、编号、频段、电源引脚及接线 | 放大器按盘位对应，频段及 GND／Vd／Vg 接线 |
| 放大器工作参数 | 放大器编号、温度 K、Vd V、Id mA、Vg V、备注 | 同一放大器不同温度下的工作值 |
| 检线记录 | 时间、装样状态、测试功率 dBm、频段 GHz、实测传输 dB、结论、测试条件／备注 | 装样前／带样品、测试功率、传输结果及异常处理 |

迁移后的旧记录可在对应端口的“查看迁移原记录”中只读查看。原始温级、放大器、检线及备注均保留；当前不新增放大／衰减链的编辑功能。旧 `.qchip` 的 XLSX／CSV 导出仍包含尚未迁移的接线记录。

旧接线登记在 `.qchip` v5 中新增 `wiring_details` 表；当前源码使用 v8。打开 v1–v7 项目先自动生成迁移前备份，旧项目未登记的新类别保持为空。支持格式可在“帮助 > 版本信息”查看；旧编译版不能直接读取新版文件。
