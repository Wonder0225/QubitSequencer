# 芯片设计图测试示例

打开同目录的 `chip_design_release_demo.qchip`，或从项目根目录运行：

```powershell
python -m qubit_sequencer gui examples/chip_design_release_demo.qchip
```

项目内嵌用户提供的设计图原图，包含 12 个演示比特 `Q_{1}`–`Q_{12}`，在逻辑构型中按 3 列、4 行排列。设计图上的标注位置全部留空，由用户手动对应；逻辑位置不代表版图实际位置，也未推断器件之间的连接。频率、T1 及 default/idle 工作点参数均是模拟数据。

## 测试步骤

编辑操作会立即保存，请先使用“另存备份”保存测试副本，再打开副本操作。

1. 在“芯片构型”页点击“查看设计图”，确认显示原图；点击“返回构型图”确认能回到结构图。
2. 再次进入设计图，开启“编辑标注”，选择要登记的比特，点击图片上的对应位置。标注的实际对应关系由你确定；也可拖动调整位置。
3. 使用左右 90° 按钮或输入角度旋转；标注应跟随图片移动，名称保持正向。滚轮缩放、拖动空白平移，“适配设计图”恢复全貌。
4. 关闭“编辑标注”，点击新标注打开参数弹窗；切换顶部 default/idle 工作点可查看不同的模拟频率。保存器件改名后，标注名称应同步更新。
5. 关闭后重新打开测试副本，确认图片、旋转角度、标注位置与名称保留。

该示例使用 v4 格式，需要 0.3.2 或当前源码运行，原有 Windows 0.3.1 发布版尚不支持。图片已保存在项目内，无需依赖原始图片路径。

如需另建示例，可运行 `python scripts/generate_chip_design_demo.py 图片路径 --output 新示例.qchip`；输出文件必须不存在。
